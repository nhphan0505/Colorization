# 🎨 A SURVEY ON IMAGE COLORIZATION METHODS UNDER RESOURCE CONSTRAINTS

## 📌 Overview

This project implements grayscale image colorization using deep neural networks.

---

## 🚀 Setup

### 1️⃣ Clone Repository

```bash
git clone https://github.com/your-username/colorization.git
cd colorization
```

### 2️⃣ Create Conda Environment
We provide automatic bootstrap scripts.

🪟 Windows
```bash
powershell -ExecutionPolicy Bypass -File .\scripts\bootstrap_conda.ps1
```

🐧 Linux / 🍎 macOS
```bash
bash ./scripts/bootstrap_conda.sh
```
